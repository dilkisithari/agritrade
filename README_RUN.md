# How to run AgriTrade

1. Copy the `agritrade` folder into `C:\xampp\htdocs\` (so the path is `C:\xampp\htdocs\agritrade\index.php`, NOT agritrade\agritrade).
2. Start **Apache** and **MySQL** in XAMPP.
3. Open **http://localhost/agritrade/setup-database.php** once and click "Import database now".
   (This imports docs/agritrade.sql, the structure all pages are written for.)
4. Open **http://localhost/agritrade/**

Admin login: `admin` / `admin123`

The old static HTML prototype was moved to `_legacy_static_prototype/` (not used).
